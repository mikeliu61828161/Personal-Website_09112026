HK Sky Invaders

Space Invaders for Android, built with Phaser, Vite and Capacitor.

Overview

HK Sky Invaders is a Space Invaders–style arcade game. It runs in the browser during development and is packaged as an Android app.

Tech stack

ToolRole
Phaser 3Game engine
Vite 5Dev server and bundler (output to dist/)
Capacitor 6Wraps the web build as a native Android app
TypeScriptLanguage tooling

Getting started

npm install
npm run dev      # http://localhost:5173/
npm run build    # production build into dist/
npm run preview  # serve the production build

Android build

npm run build
npx cap add android   # first time only
npx cap sync android
npx cap open android  # opens Android Studio

In Android Studio, wait for the Gradle sync, choose an emulator or a USB-debugging device, then press Run. After changing game code, rerun npm run build && npx cap sync android.
